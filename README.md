## 📖 Acerca del proyecto

Este repositorio contiene una guía de estudio digital
orientada a la asignatura Economía.

El proyecto surge como una iniciativa estudiantil destinada
a centralizar el material de estudio, facilitar el repaso
de los contenidos de la asignatura y contribuir a la
preparación de parciales y exámenes finales.

La finalidad es disponer de una herramienta de consulta
accesible desde el navegador, que permita complementar
el material utilizado durante el cursado.

## 🎯 Objetivos

- Centralizar los contenidos de la asignatura.
- Facilitar la comprensión de los conceptos económicos.
- Proporcionar una herramienta de consulta rápida.
- Optimizar el tiempo dedicado al estudio.
- Facilitar la preparación de parciales y exámenes finales.
- Promover el aprendizaje autónomo.
- Compartir material de estudio entre estudiantes.

## 📚 Material de estudio

La plataforma está pensada para ser utilizada como
complemento de las clases teóricas, las actividades
prácticas y la bibliografía correspondiente a la asignatura.

Se busca favorecer la comprensión y la relación entre
los conceptos económicos, en lugar de limitar el
aprendizaje a la memorización de definiciones.

## 💻 Tecnologías y distribución

El material se encuentra integrado en una página HTML,
lo que simplifica su distribución y permite consultarlo
directamente desde un navegador web.

El proyecto está preparado para su publicación mediante
GitHub Pages.

## 🚀 Ejecución local

También es posible acceder al material de manera local,
clonando el repositorio:

    git clone https://github.com/Javier-Sinuka/economia_resumen.git
    cd economia_resumen

Una vez descargado, basta con abrir el archivo `index.html`
desde cualquier navegador web.

## 🤝 Contribuciones

Cualquier sugerencia, corrección conceptual o propuesta
de mejora es bienvenida.

Algunas posibles contribuciones son:

- Corrección de errores conceptuales.
- Ampliación de explicaciones.
- Incorporación de ejemplos prácticos.
- Incorporación de material complementario.
- Mejoras en la presentación del contenido.

Para realizar una contribución, se puede abrir una Issue

## ⚠️ Aclaración importante

**Este material NO constituye un apunte oficial de la cátedra.**

Se trata de una iniciativa estudiantil desarrollada con
fines exclusivamente educativos, cuyo objetivo es
complementar el material proporcionado durante el cursado.

El contenido puede presentar errores, imprecisiones u
omisiones, por lo que se recomienda contrastar la
información con la bibliografía oficial de la asignatura
y las explicaciones de los docentes.

El uso de esta herramienta no reemplaza la asistencia
a clases ni el estudio del material oficial.
